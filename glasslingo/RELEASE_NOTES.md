# GlassLingo 0.17.0

- 游戏和观影的持续字幕加入字号/中心稳定器，小幅 OCR 框抖动不再立即改变排版；真正布局变化需多次独立 OCR 确认，流式绘制不算确认次数。
- 流式换成两行时向下展开，保持首行基线；优先使用中心对称的可用宽度，减少碰到屏幕边界时左右跳动。
- 高置信度、明显变化的新句可减少一次 OCR 确认；清晰高置信度小字跳过重复放大识别。观影采用较积极阈值，游戏保留低占用检查周期。
- 观影本地检查周期约 50ms、静止校验 200ms；API OCR 仍保留 2.5 秒限频。
- SSE 输出节流由 70ms 缩短到 24ms，观影已接收文本在约 64ms 平滑追平，减少一批文字突然跳完再停顿的观感。
- 整句内容未变而 OCR 分行变化时不取消重发翻译；显示窗口边界不变时减少原生移动/缩放与强制布局。
- 保留一个持续区域一段字幕、一块底色及扩窗行为。

## 0.16.0

- 持续/跟随字幕区域改为单段呈现：一个区域始终只绘制一个文字块和一个连续底色块，不再依赖 OCR 分框的间距、字高、基线或数量决定是否合句。
- 兼容 API 的持续原位字幕请求整段翻译，不再使用每个 OCR 小框的行编号协议；整段缓存独立命名，避免旧的逐框译文替代整段翻译。
- 原文整体包围盒决定字幕中心，原始文字框的代表字高决定字体，避免多行包围盒把观影字号放大。
- 旧锚点、部分流式和只有尾句缓存的情况也进入单段呈现，中文片段之间不插入额外空格。
- 开始持续框选前关闭旧的一次性覆盖层，保留其它持续区域。
- 全屏/普通逐点覆盖继续使用原有定位规则；持续选区内的全部识别文字会作为一段字幕显示。
